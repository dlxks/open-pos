# Open POS Register

The Register is the Flutter application for store setup, staff sign-in, catalog
management, and cashier checkout. It supports role-based access, a versioned
catalog cached in local SQLite, cash sales, and an offline sync queue. New stores
start with an empty catalog. Android, iOS, Windows, macOS, and Linux runners are
generated and ready for platform-specific polishing.

See the root [README](../../README.md) for setup and deployment. Run
`flutter test` for unit and widget coverage, and `npm run test:e2e` for
Playwright browser coverage.
